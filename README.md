# plp-python-week4 - Functions

This assignment focuses on creating reusable functions in Python.

File descriptions:
- welcome.py - contains a welcome function that greets users by name shows function reuse.
- toolbox.py - contains three utility functions: double for doubling numbers, is_pass for checking pass or fail
  and greet for personalized greetings.

  Hardest function:
  The hardest function was greet() because it was the first time I used default parameter. I had to figure out how to make it
  return "Hello, Amina!" when I only pass the name, but return "Habari, Amina!" when I pass both name and greeting. I understood that greeting="Hello" is a fallback value.
